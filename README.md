# NoteBox

NoteBox is a small notes page. Everything runs in the browser and your notes are kept on your device.

## What it does

- Add a note with a title and see it in the list.
- Search the notes by typing in the search box and the list narrows down.
- Pin a note so it moves to the top of the list with a Pinned label.
- Adding a note with an empty title shows a clear message and adds nothing.
